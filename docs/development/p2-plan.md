# P2 活动片段

2026-10-27，用户完整开发授权下实施。规则与存储契约见 [数据模型](../technical/data-model.md)，运行命令沿用 [Web UI](web-ui.md)。

“活动片段”按时间倒序列出分组，提供代表图及逐条原始来源；停止/暂停后可以选择多个片段合并，或在某条来源之前拆分。手动编辑只改来源关系，不改原图和 OCR。分组不是阅读/工作时长或学习成果的证明。

实现包含持久成员关系、批次续建、schema 事务迁移、来源删除/缺图失效、OCR revision、手动编辑回滚、分页与本地鉴权。自动化覆盖规则边界、拆分/合并、文件故障、OCR 更新及 API 暂停限制。整个项目继续接受后续阶段集成检查，统一记录于 [测试文档](testing.md)。

初始规则属于可配置启发式，不宣称真实语义分段精度通过；真实使用、复杂标题和长期规模验证仍待完成。
