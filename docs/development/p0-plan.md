## P0-01 开工确认与运行依赖

- 检查 Git 状态和当前工程，使用 uv sync --locked 复现环境；保留用户无关改动。
- 根据实际捕获与图像方案，用 uv 声明最少运行依赖并更新锁文件，不重建另一套工程或手动 pip 管理。
- 正式数据/配置路径、空闲策略和配置样例已落实，见开发说明；测试使用单独的忽略目录。
- 交付：实际版本、依赖来源/许可证、路径及可复现命令。

## P0-02 捕获最小实验

- 确认选定版本 API、Windows/位数兼容与发布包；首个候选见决策记录。
- 用户在实验程序中明确开始后，按当前 HWND 捕获无敏感内容窗口，检查目标、颜色和尺寸。
- 验证 row pitch、缓冲区生命周期、停止与回调线程语义、尺寸变化。
- 覆盖遮挡、关闭、重建、最小化和快速切换；保存环境及逐项结果。
- 实验失败时先解决或给出可验证替代方案，再扩展完整流水线；不静默退回整屏裁剪。

## P0-03 调度、隐私与并发

- 按 [架构契约](../technical/architecture.md) 分离监控、调度、后端与提交职责。
- 实施开始/暂停/退出、窗口稳定等待、捕获前及提交前检查、generation 失效与有界队列。
- 保证暂停完成屏障、失败节流、丢弃计数和资源回收；回调不执行重型处理。
- 用可控假后端覆盖并发与错误，再做 Windows 验证。

## P0-04 去重、存储与恢复

- 配置化实验阈值，比较最后一次成功保存的参考图；覆盖局部及累积变化。
- 按 [数据契约](../technical/data-model.md) 保存 Observation 与图片，区分捕获/保存时间并建立 schema 版本。
- 验证编码、文件、数据库失败，中断恢复、单图超额、孤儿文件与清理重试。
- 实施保留与图像配额的启动/运行维护及明确删除方法；不能把图像配额称为整个目录硬上限。

## P0-05 配置与调试控制

- 轻量 UI 显示真实状态、目标、时间、变化分数、原因、队列长度、丢弃计数和错误。
- 提供开始、暂停、退出、打开目录与查看图像；暂停/退出等待时不虚报完成。
- 配置校验、首次初始化、重启/动态生效行为有说明；事件有界，持久日志不泄露内容。
- 更新真实入口、配置、停止、删除与排错说明。

## P0-06 验收与交付

- 执行 [自动化与 Windows 矩阵](testing.md)，准确记录通过、失败及未验证项。
- 记录 1 小时与 8 小时资源、图像增长、队列及稳定性；不填写估计数值。
- 按用户选择，由用户手动开始并正常使用电脑，结束后分析本地记录；步骤见 [日常使用长测](real-usage-test.md)。受控场景与实际使用证据分别注明，不将日常偶然操作当作完整矩阵验证。
- 更新支持环境、依赖、架构、参数、运行说明和剩余限制。
- 交付可运行版本、测试证据及 P1 最小建议；不自动进入下一阶段。
