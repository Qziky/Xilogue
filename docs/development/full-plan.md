每一职责独立提交源码、对应测试与必要文档；发现缺陷另行修复。仅本地提交，不推送。未知模型/设备能力通过检查显示不可用，不虚构精度、性能、安装或验收通过。

## 运行边界

- 延续 uv、Python 3.11、根目录 src、回环 Web UI 和默认停止。
- 新配置使用可向后兼容的默认值，schema 迁移事务化；不自动导入用户历史实验目录。
- 模型仅访问固定本机 Ollama；可选嵌入模型未安装时不自动下载或使用云服务。
- 截图、页面正文和模型输入均为不可信证据，不能授权工具、命令或网络访问。
- 暂停、退出、源删除与派生内容写回必须协调，任何新功能不能使被删来源复活。
- 人工验证仍统一记录在 [测试文档](testing.md)，各阶段实现与限制随开发更新。
