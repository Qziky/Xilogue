# 每日回顾与反馈

2026-10-27。每日回顾默认选择本地“昨天”，按浏览器 IANA 时区确定日界，覆盖夏令时的 23/25 小时日。先完成 OCR 和本地片段摘要，再明确生成回顾；无有效来源时保持空态，不补造文字。启用自动 AI 后，只在采集运行且桌面可用时，于摘要完成和定期维护生成昨天的回顾，使用 review_timezone（默认 Asia/Shanghai）；回顾排序本身不额外调用模型。停止/暂停时可以手动生成回顾。

回顾从当天引用构建卡片，不直接复制跨午夜 Session 的整个摘要。每条结论都能打开原图；排序显示模型重要度、置信度及来源依据，不使用观察跨度推测用户学会或完成任务。界面每页 30 条，可以继续加载。数据仍只在本机。

可标记有用、无用、稍后看、已掌握、不再推荐，单独隐藏或保存最长 2000 字符的用户修正。修正标为用户注释，不冒充 AI 原文或已验证事实。无用/已掌握/不再推荐及隐藏卡片默认不显示，可包含隐藏后清除反馈；不再推荐也抑制具有相同规范化主题的其他片段。反馈依附来源 Session，删除源后同步清理，不保留已删证据中的私密主题。

schema v5 使用 daily_reviews、review_cards、review_feedback。卡片连接有效 Insight；模型重新生成、Session revision 变化或来源删除会让旧卡片级联失效，重新生成后才能纳入新回顾。生成操作事务化，失败保留原快照。时区数据库依赖 tzdata 2026.5，由 uv 锁定在项目环境，不改系统时区。

规则/日界/故障/删除/跨午夜及 API 测试已添加；真实长期内容价值与用户回顾有用率仍需独立验证，不能由合成材料推断。
