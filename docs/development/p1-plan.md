# P1 本地 OCR 与原始记忆检索

更新：2026-10-27。P1 的原始范围为本地 OCR 与文字搜索；用户随后授权 [完整开发](full-plan.md) 继续 P2–P7。本文保留 P1 实现与阶段验证记录，P0 验收待办仍在 [测试文档](testing.md)，不自动开始采集。

## 范围与顺序

1. 核对本地 CPU OCR 引擎及模型来源，项目范围声明依赖、锁定版本；使用合成中文、英文和代码材料验证文字、坐标及离线推理。
2. 为现有库建立事务迁移，保存 OCR 原文、逐行坐标/置信度/引擎版本；持久任务与 Observation 一起创建，重启恢复领取中任务，失败有上限重试。
3. 增加独立 OCR Worker；仅处理 ready 的已保存原图，捕获回调不执行 OCR。暂停失效旧任务并阻断内容提交，恢复后重试；退出等待工作线程。删除或缺图立即移除任务、文本和索引，旧结果不能复活来源。
4. 实现 SQLite FTS5 子串索引及中文一/二字短查询回退，按应用和时间筛选；文字按字面查询，保留原文与原图回源。提供明确发起的离线处理、搜索命令及轻量检索界面。
5. 按上述职责原子提交，完成故障、暂停/删除竞态、迁移、短词和真实本地 OCR 合成材料验证。真实日常数据不自动导入测试，不提交图片或数据库。
6. Web UI 迁移后继续补齐 P1 来源管理：无需关键词浏览原图、稳定游标分页、OCR 状态筛选、单条失败重试及带确认的来源删除。沿用删除传播与暂停契约，不进入 Session 或 AI。
7. 增加明确发起的仅 OCR 批次：不启动捕获或读取前台窗口；处理本轮开始时已到重试时间的已存来源，结束后自动暂停。允许在自动 OCR 配置关闭时显式执行，保持桌面可用性检查和旧结果提交屏障。暂停后的在途推理结束后释放本地 OCR 会话。

## 验收

当前实现：schema v2、持久任务、文字/坐标与 FTS5、本地 CPU OCR、暂停/退出提交屏障、配置、检索及 CLI 已完成。界面按用户要求迁移为 [本地 Web UI](web-ui.md)，控件和合成浏览器交互已验；受控并发、迁移、故障、搜索及命令入口测试通过，真实合成中文/英文/代码三图处理与预设检索通过。使用见 [OCR 说明](ocr.md)。真实浏览器 WGC 联动、日常使用及长期稳定性仍待完成，不宣告完整 P1 验收通过。

P1 来源管理已增加分页浏览、状态筛选、单条重试和删除；验证记录继续合入原测试文档。没有增加 Session 数据表或模型调用，也不将浏览器合成材料验证视为真实 WGC 联动验收。

仅 OCR 批次与暂停后会话释放已实现，通过自动化、合成页面交互与真实本地 OCR 三图检查。仅 OCR 与采集开关明确区分；失败退避不在本轮等待。完整结果与长期资源待办仍以原测试文档为准。
