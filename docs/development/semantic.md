# 相关检索与跨日主题（P5）

Web UI 的“相关与主题”提供字面词项相关度和可选向量。嵌入默认使用本地 Ollama，也可独立选择 OpenAI 兼容 API，与摘要使用不同提供商；API 字段和发送许可见 [AI 提供商](analysis.md)。原始文字搜索仍使用 FTS；相关结果显示命中词、余弦分数和计算方式，不能据此断言用户已学习或完成任务。索引最多扫描 3000 个近期活动片段；主题最多汇总 1000 个有效分析，各限制由接口返回。

暂停后点击“建立本地索引”，处理已有文字，结束自动暂停，不启动截图。默认不启用持续语义处理。向量记录模型名、模型摘要、维度、文字摘要和活动修订号，模型版本/维度不匹配不混用；来源删除或修订立即失效。主题日期由实际引用的来源按所选时区计算，隐藏和不再推荐反馈同时应用。

`uv run --locked python scripts/setup_embedding.py` 显式下载官方 embeddinggemma 300M（约 622 MB）至项目 `data/embedding-models`，验证固定 SHA256、记录来源。默认 `embedding_port=0` 按需启动拥有独立回环端口的 Ollama 子进程，仅使用该缓存，应用退出结束自有服务。已有服务可配置 11434/11435；应用不终止外部服务。分发运行时可用 `embedding_models_dir` 指定预先准备的离线缓存。此安装不更改全局环境或用户原模型目录。

模型不可用时相关查询明确提示降级为关键词。每批/查询后卸载本次加载的模型并检查 `/api/ps`，保留外部服务原本驻留模型；释放失败显示错误并在退出重试。

2026-10-27 合成实测：768 维，两项索引成功、无失败；两次独立本地服务实验均通过，最后一次约 5.26 秒（仅该合成批次，不是一般性能承诺）。报告 `data/semantic-acceptance/20261026T172931_d8480087/report.json`，含源码摘要、配置与环境；结束时 `after_models=[]`、无工作线程存活。隐私截图与原始数据库不提交。

官方来源：[embeddinggemma](https://ollama.com/library/embeddinggemma)、[嵌入 API](https://docs.ollama.com/api/embed)。
