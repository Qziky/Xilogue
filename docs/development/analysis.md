# 本地分析与证据校验

2026-10-27。活动片段可以明确发起“生成缺失的本地摘要”或单段重新生成；要求停止/暂停，随后只运行分析，不采集窗口或执行 OCR。默认不启用自动 AI。配置 ai_enabled=true 后，采集期间每 2 秒发现稳定片段（默认 60 秒无新来源，且 OCR 没有待处理/运行/可重试任务），自动排队；不会下载模型。semantic_enabled 同样选择稳定片段生成向量。重复发现不重置失败次数，活动变化撤销旧结果并等待重新稳定。暂停/停止不触发自动发现。

Provider 固定访问 127.0.0.1:11434，不接受远程 URL、系统代理或重定向，不提供执行工具。默认 recorder-vision:balanced；先核对已安装模型和 completion 能力，拒绝云端标识和 remote_host/remote_model。Ollama 不可用时保留持久失败任务、退避和重试上限，不影响采集或文字检索。重新发起分析可重置失败任务。

每段最多使用最近 8 条已完成 OCR 来源，各截取 600 字符；模型只能引用这些有界输入的来源 ID 及指定原文片段。结构、长度、有限数值、来源 ID 和原文子串均校验，不通过不入库。摘要、主题、关键词、重要度、置信度和不确定项连同模型及时间保存；界面始终标为 AI 草稿。引文校验不能证明推论正确，模型置信度不是客观精度。

任务领取 token、Session revision、来源有效性和暂停提交屏障共同阻止旧结果写回；删除来源、拆分/合并或 OCR 更新立即清除/失效旧分析。启动恢复中断任务，取消不消耗失败次数，异常最多自动尝试 3 次。批次结束自动暂停；不等待尚未到期的退避。退出等待当前请求及清理；暂停不能立即中断已发送的原生模型请求，但旧结果不再提交。

稳定片段的重复发现先检查持久任务/结果，不反复读取已处理的全部来源。单个自动片段最多 4096 条来源，超过后另建片段。概览同时显示后台分析、显式向量查询及释放未确认的状态；退出屏障等待查询完成后再结束自有服务。

批次 Provider 记录开始前已驻留的模型，只卸载本次自行加载的模型；结束显式发送 keep_alive=0 并核对 /api/ps，保留原驻留模型。清理无法确认会显示 model_release_unconfirmed，不能把工作线程退出等同于显存已归还。默认模型缺失时请自行按环境文档安装/注册，应用不修改 Ollama 全局设置。

本机实测 Ollama 0.40.11，模型文件沿用既有 9B。首轮合成测试一段引用校验失败，已拒绝；将来源及原文选项纳入动态 JSON schema 后，两段通过（本地 data/ai-acceptance/20261026T163820_459df3a2/report.json）。任务结束模型列表为空，临时服务已停止；整机显存 2526 MiB 是其他进程的合计背景占用，不代表模型仍驻留。该小样本不是正式摘要质量或性能验收。
