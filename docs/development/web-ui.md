# 本地 Web UI

更新：2026-10-27。正式本地 Web UI 已覆盖采集概览、原文检索、活动片段、本地分析、每日回顾、相关检索和设置。验收结果及剩余事项统一见 [测试记录](testing.md)。

界面使用 Fluent UI React v9 和 Fluent 图标，提供右上角的“跟随系统 / 浅色 / 深色”。偏好只含模式名称，保存在本机浏览器的 host-only Cookie 中，以便应用随机端口改变后仍能保留；不包含令牌或活动数据。扩展弹窗跟随系统主题。

## 启动与停止

先退出旧版 Tkinter 或使用同一数据目录的程序，在项目根目录执行：

```powershell
uv sync --locked
uv run --locked xilogue
```

程序只在 127.0.0.1 的自动分配端口监听，输出 `Web UI: ...` 完整链接，并打开系统默认浏览器。每次启动均未开始截图或 OCR，需点击“开始采集”。也可以使用：

```powershell
uv run --locked xilogue --no-browser
uv run --locked xilogue --port 8765 --data-dir data/try-web
```

--no-browser 需要自行复制终端的完整链接；--port 只指定本机端口，不支持对外监听。链接含本次运行凭证，保留在本机，不转发或提交 Git。服务重启后旧凭证失效，需使用新链接。

“暂停”后等状态显示“已暂停”，旧截图及 OCR 结果不能再提交；“退出程序”会停止服务并释放捕获资源、线程、端口和数据目录锁。网页显示退出请求后，等终端回到提示符再关闭终端。终端 Ctrl+C 同样执行清理。关闭网页会尽力请求暂停，但不保证请求到达，也不会退出后端；不要用关闭网页代替可靠停止。

普通操作等待响应时，暂停和退出仍可使用；它们不等待普通控制命令锁。

只想处理本地积压文字时，点击概览的“仅识别已保存图片”。它不会创建捕获后端或读取前台窗口，只识别本轮开始时已到重试时间的已存来源；即使设置中关闭了自动 OCR，也允许这一明确操作，不改变配置。仍检查桌面可用性，桌面不可用时等待，随时可暂停或退出。批次无可领取任务后释放 OCR 会话并自动暂停，不等于所有失败任务已成功；退避未到期的任务不会在本轮等待，可稍后再执行或先重置失败任务。

“已暂停”表示旧结果不能再提交，可能仍有一项不可打断的原生推理在结束。页面会显示会话是否仍加载；推理返回后释放会话。仅 OCR 批次完成后，“开始采集”是另一个明确动作，不会悄悄开启录屏。关闭再启动仍默认停止。

## 页面

| 页面 | 已实现操作 |
| --- | --- |
| 采集概览 | 开始/恢复、仅识别已保存图片、暂停、退出；真实模式与目标；最新原图、捕获时间、变化/耗时、队列、计数、错误、OCR 会话与存储统计；有界事件 |
| 记忆检索 | 原始记录分页浏览；中文短词、英文和代码字面查询；进程、本地日期时间及 OCR 状态筛选；原图、原文、坐标及置信度详情；单条重试和删除 |
| 采集设置 | 采样间隔、空闲策略、保留期、图像配额、OCR 开关/线程数、进程排除；暂停时保存并应用，或从文件重载；打开专用数据目录 |
| 活动片段 | 自动分组、来源和代表图、手动拆分合并、缺失摘要或单段重新分析 |
| 每日回顾 | 本地日界、当天原文证据、有用/稍后/已掌握/不再推荐等反馈、隐藏和用户修正 |
| 相关检索 | 关键词相关度、可选本地向量及明确降级、跨日主题回源 |
| 扩展与备份 | 设置页下载扩展、临时配对/撤销；暂停后下载一致性备份 |

完整配置中未显示的高级参数保留原值，可通过所选配置文件修改后重载。配置文件仍为 version=1，schema 版本统一见 [数据模型](../technical/data-model.md)。离线 OCR/搜索命令仍见 [OCR 说明](ocr.md)。[日常使用长测](real-usage-test.md) 使用同一 Web UI，并在概览显示分钟数、性能样本数及诊断错误。

进入“记忆检索”自动读取最新记录。关键词留空时可浏览未识别、正在识别及识别失败的原图；填写关键词后只匹配已识别文字。每页 30 条，按捕获时间与 ID 倒序；可前后翻页，新增记录需点“刷新最新记录”回到第一页。界面显示本页数量，不把它当作筛选后的总数。时间筛选起始包含、结束不包含，结束必须晚于起始。

详情显示 OCR 状态与尝试次数。失败记录可在停止或已暂停时点“重试这条 OCR”，仅重置所选任务；之后可在概览点“仅识别已保存图片”，或在自动 OCR 开启时恢复采集处理。重置本身不启动处理。“删除这条记录”需再次确认，取消不会删除；确认后清除该来源的原图、OCR、索引和任务，旧 Worker 无法复活文字。文件删除失败时先隐藏来源，提示“尚待清理”，每分钟维护及下次启动继续清理；未完成物理清理不宣称图片已删除。该操作可在采集运行中使用，仅删除所选来源，不会阻止之后的新采集。删除后刷新列表回到第一页，并清除页面已显示的该条原图；其他浏览器页需刷新才能更新其既有显示。

## 实现边界

Python 负责 WGC、调度、OCR 和 SQLite；FastAPI/Uvicorn 提供受保护的回环接口，已构建的 React/Fluent 静态资源随 wheel 分发，不使用 CDN，普通运行不需要 Node.js。修改前端需要本地 Node.js 和 npm，命令见[开发环境](setup.md)。后台接口可继续复用，页面与捕获实现分离。FastAPI [来源说明](https://fastapi.tiangolo.com/tutorial/cors/) 和 Uvicorn [资源限制](https://uvicorn.dev/settings/) 为技术参考，实际边界以本项目测试为准。

数据 API 必须带每次启动的随机令牌；写操作还需同源 Origin 与 JSON POST，错误 Host/来源拒绝，变更请求体最多 64KiB。关闭访问日志；HTML、图片、配置和 OCR 响应禁止缓存。CSP 禁止外部脚本、内联脚本、`unsafe-inline`、`unsafe-eval` 和页面嵌入；主页面每次响应生成独立样式 nonce，供 Fluent 的 Griffel 运行时样式使用。用户内容以文本渲染。公开静态资源只有应用页面和白名单脚本/样式，数据库、模型、任意文件不通过静态目录暴露。

页面标题带随机会话标记，前台和提交检查均保守排除匹配窗口；不对所有浏览器进程一刀切。请在普通独立系统浏览器窗口使用，未透传页面标题的内嵌浏览器不在当前自身窗口排除保证内。合成环境已验证控件和标题检查，真实 Edge/Chrome 的 WGC 联动、关闭浏览器/休眠及持续运行仍待完成，不能据 DOM 测试宣称通过。

UI 改版不自动升级已打开的旧 Python 进程；请先暂停并退出旧窗口再重新运行。当前既有 P0/P1 实机及长测待办继续保留，不要求用户现在配合补验。
