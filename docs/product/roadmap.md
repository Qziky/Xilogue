# 开发路线与阶段门槛

P0–P7 开发功能已落地，完整实机、扩展安装及长测验收尚未完成。2026-10-26 用户暂存验证，2026-10-27 授权完整开发；实施见 [完整任务单](../development/full-plan.md)。开发顺序调整不代表验收通过。

| 阶段 | 工作与交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 可靠采集 | 根目录正式工程；WGC spike；调度、隐私、去重、存储、调试与错误恢复 | 按 [P0 测试规格](../development/testing.md) 留证，未验证项明确，不以原型测试替代 |
| P1 OCR 与原始记忆检索 | 本地 OCR Worker；文本与坐标；可恢复任务；中文/英文/代码及短关键词搜索；原图查看 | 找得到已知文字；OCR 失败不影响采集；删除与任务恢复一致 |
| P2 Session 活动聚合 | 按应用、标题相似度、时间间隔规则分组；代表图与来源；查看、拆分、合并 | 分段合理；重复文本可控；能回到完整证据；中断可恢复 |
| P3 本地 AI 分析 | Provider 接口；Session 级结构化摘要、主题、关键词、重要度、置信度、不确定项；来源校验 | 输出有据且通过结构校验；模型不可用不影响采集/搜索 |
| P4 每日回顾 | 汇总 Session 摘要；主题排序；昨日卡片；有用/无用/稍后看/已掌握/不再推荐反馈 | 每个结论可回源；无内容时不凑摘要；用户能隐藏或纠正推荐 |
| P5 语义检索与跨日主题 | 先优化关键词与筛选，再按必要性评估轻量向量方案；展示证据及相关依据 | 模糊查询找回有依据；源删除时索引与派生内容一致清理 |
| P6 浏览器扩展 | URL、标题、可见正文、可用字幕、活动时间；与桌面来源关联；受控本地通信 | 授权、无痕、来源及本地接口安全边界经过验证 |
| P7 产品化与长期运行 | 托盘、设置、可选启动、安装/更新/卸载、备份、迁移、资源与无障碍 | 多日运行、恢复、升级及删除有实际证据和清楚的数据选择 |

阶段需要单独验收。用户于 2026-10-27 明确要求继续完成所有开发，按 [完整开发任务单](../development/full-plan.md) 推进 P2–P7。P0/P1 待完成项目保留在原测试矩阵；这不是验收放行。隐私、错误处理、容量和恢复要求继续适用，发现实际缺陷必须修复。

每日回顾不单凭停留时长判断价值，可结合主题、新颖性、重复访问和实际交互。排序反馈不能无提示删除原始证据。

全屏、多显示器同时采集、音频、复杂 Agent、知识图谱和短时环形缓冲保留为远期研究，不承诺并入上述任一阶段。正式 UI 技术、OCR 引擎和模型需按 [决策记录](../technical/decisions.md) 的时点验证。
