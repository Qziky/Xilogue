# 隐私与数据生命周期

状态：各阶段必须满足的产品要求，尚非已通过的实现保证。2026-10-26。

## 用户控制

- 每次启动默认停止，由用户明确点击开始后采集；不自动恢复上次采集状态。
- “仅识别已保存图片”是另一个明确发起的操作，只处理本地既有来源，不开启屏幕采集；结束后自动暂停。手动暂停仍阻断旧结果，推理返回后释放本地 OCR 会话；页面不得把提交暂停等同于即时打断原生推理。
- 清楚显示当前状态、暂停和退出入口。暂停请求执行中显示“正在暂停”，完成屏障后才显示“已暂停”。
- 暂停完成后，不得新增截图、Observation 或由旧采集任务提交的内容。后续 OCR/AI 的旧任务同样需要取消或阻断提交，不能在暂停后偷偷继续生成记录。
- 配置保存、空库初始化和用户明确发起的数据删除不等于屏幕采集。要区分这些写入与新增采集内容，避免用空数据库出现与否代替采集验收。
- 开机启动仅是后续可选功能；即使允许启动程序，也不等于允许自动采集。

## 捕获前与提交前检查

只允许普通已登录用户的交互桌面会话，不以服务或管理员运行作为默认方案。锁屏、安全桌面、目标失效、权限失败或状态不确定时停止接受内容，不绕过 Windows 或应用的保护机制。

排除列表首先按进程名、大小写无关匹配；捕获前检查，提交前重查。切换、暂停、排除或退出使旧任务失效，旧候选不能因后台处理延迟而落盘。

标题、PID、HWND 及桌面状态都有时效性，不能只在会话建立时检查一次。暂停完成与并发提交的协调按 [架构](architecture.md) 实现并验证。

进程名排除不能可靠识别同一浏览器中的无痕页、密码字段或所有敏感内容。UI 必须如实说明并提供主动暂停；不能宣传自动过滤全部私人信息。

## 本地边界

截图、窗口标题、活动元数据、OCR、模型输入和派生内容默认只保存在本机。P0 不添加网络上传、后台同步或模型调用；安装依赖需要访问软件源，与上传屏幕记录是不同操作。

2026-10-27 用户要求可选 API 提供商，摘要和向量分别设置目标、模型、密钥和发送许可，默认仍使用本地 Ollama。界面显示服务目标及发送字段，只有主动勾选并保存后才能发送相应用途的文字；修改地址需重新选择许可。原图与本地数据库不上传，但 OCR / 网页文字、截断标题等可能含私人内容。字段清单、DPAPI 凭据保存、备份许可重置和提供商副本边界统一见 [AI 提供商](../development/analysis.md)。本地模型仍需核对实际调用路径，不因名称含“local”就假定离线。

服务仅绑定 127.0.0.1，主 UI 数据与控制 API 校验每次启动的随机 Bearer 令牌、Host、请求来源，变更只接受同源 JSON POST。令牌通过启动链接 fragment 进入 sessionStorage 后移除，不使用 Cookie 或查询参数传令牌。不启用公开 OpenAPI、任意文件静态目录或请求访问日志，常规 JSON 请求体最多 64KiB。P6 扩展只对专用 `/api/extension/` 通道开放已配对扩展精确 Origin 的 CORS，使用独立 1 小时令牌和单次票据，不能访问主 UI 数据接口；图片通道最多 3MiB，受前台、桌面、模式和暂停屏障控制，见 [扩展边界](../development/browser-extension.md)。

界面主题偏好使用本机浏览器中名为 `xilogue_theme` 的 host-only Cookie，仅存 `system`、`light` 或 `dark`，不存令牌或记录。Cookie 作用于回环主机，因此同一浏览器中访问 `127.0.0.1` 的其他端口也可能收到该无敏感内容的偏好值；清除浏览器 Cookie 后恢复跟随系统。

普通系统浏览器页面的标题带有本次启动的随机标记，捕获前和提交前据此排除自身界面，保留 HWND/PID/进程创建信息的既有校验。该规则不读取浏览器 URL，也不保证识别未透传页面标题的嵌入式浏览器；当前应使用普通独立 Edge/Chrome 窗口，真实 WGC 联动仍待完成。所有用户标题及 OCR 内容以文本渲染，不解释为 HTML；图片通过鉴权请求取得，不将令牌附在图片 URL。

手动暂停仍需等到“已暂停”。页面卸载会尽力发送暂停请求，但浏览器崩溃或强制关闭不保证送达；关闭网页不等于退出服务。可靠停止应使用“暂停 / 退出程序”，终端 Ctrl+C 也会回收引擎。旧测试窗口不会因更新源文件自动关闭或升级。

## 日志与界面

调试界面可以临时显示当前窗口标题；持久日志默认不含敏感标题、截图内容、OCR 原文或未经筛选的异常上下文。日志和事件队列必须有上限，错误可诊断且不无限增长。

真实记录、数据库、配置秘密、调试截图和含个人信息的测试材料不得提交代码仓库。使用人工构造的色块、文本和无敏感信息窗口验证采集。P3/P5 只向回环 Ollama 发送有界文字，不发送云端；截图中的指令不能授权工具或执行命令。自动 AI/向量默认关闭，用户可显式启用或手动批处理，退出清理本次模型和自有服务。

## 保留、配额与删除

从 P0 起提供可配置期限、图像配额和明确的本地删除方法，不推迟到产品化阶段。清理时机、统计口径及一致性要求见 [数据契约](data-model.md)；用户应能知道数据实际存在哪里。

删除源证据时清理或失效所有派生内容，并阻止旧任务恢复被删数据。保留期限到达后，即使没有新截图，也要按已定义的启动/运行维护策略清理；维护活动和采集提交分开记录。

P0 至少支持停止并退出程序后清空该应用专用数据目录的说明。P1 Web 详情支持经再次确认的单条来源删除，文件清理失败时明确提示待清理；其他浏览器页已经显示的内容须刷新才更新，不承诺远程撤回已显示或外部复制的数据。P7 支持显式备份导出；批量时间范围删除和加密仍待后续评估。程序不得删除其他应用或历史实验的数据目录。

“删除”指本应用管理的可访问数据与派生内容清理，不承诺 SSD、操作系统备份或用户外部副本被安全擦除。P7 显式备份包含私人原图、文字、派生索引与配置，没有加密；来源删除不会撤回已下载 ZIP 或外部副本。备份不包含模型、日志和启动令牌，恢复只发布到新目录，不覆盖已有数据，见 [维护说明](../development/distribution.md)。
